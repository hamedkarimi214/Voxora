# VOXORA

**A Developer-Focused Real-Time Audio Processing and Speech Recognition Project**

VOXORA is a C#/.NET project focused on exploring real-time audio processing and speech recognition workflows. The long-term goal is to transform microphone audio into usable text through a modular and maintainable software design.

## Current Development

VOXORA is under active development. Its current capabilities and architecture are evolving as the project progresses.

## Technology Stack

- C#
- .NET 10
- WPF
- CommunityToolkit.Mvvm
- NAudio

## Project Goals

- Capture audio from a microphone.
- Explore audio streaming and buffering.
- Integrate speech recognition into an audio-processing workflow.
- Build a modular foundation for future real-time processing.
- Support a maintainable and extensible codebase.

## Project Status

This project is a work in progress. Features listed as goals may not yet be implemented.

## Development

The project is developed using Visual Studio and the .NET SDK.

To get started:

1. Install a compatible .NET SDK.
2. Clone or download the repository.
3. Open `Voxora.slnx` in a compatible version of Visual Studio.
4. Restore NuGet packages and build the solution.
